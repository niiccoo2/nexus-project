# Description

## basic info

Our project is a space invaders clone but cooler and more modern.
You fly a spaceship and defeat waves of alien spaceships.

You use the hand gesture controls instead of keyboard or mouse. 

## features

- you play by using your webcam and using hand gestures

- power-ups

- upgrades in a shop

- leaderboard

## language

we used svetle and js for the game

for the hand tracking we used mediapipe ai 

game engine: svetle + phaser 3
